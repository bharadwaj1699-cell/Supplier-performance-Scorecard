# 📊 Supplier Performance Scorecard

## Overview
This project is an interactive Power BI dashboard built to analyze supplier performance and procurement KPIs.

## Objectives
- Monitor supplier performance
- Analyze procurement spend
- Track lead time and on-time delivery
- Evaluate supplier quality and compliance

## Tools Used
- Microsoft Power BI
- Power Query
- Microsoft Excel

## Dashboard KPIs
- 💰 Total Purchase Value
- 🚚 Average Lead Time
- ✅ On-Time Delivery %
- ⚠️ Defect Rate %
- ⭐ Quality Score
- 📋 Compliance Status

## Dashboard Features
- Interactive slicers
- Supplier ranking
- Monthly spend trend
- Category-wise procurement spend
- Compliance analysis
